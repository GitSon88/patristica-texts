# OCR damage inventory — documentation only, NOT applied

The 38-volume scan and several archive.org volumes carry two recurring OCR
substitutions: **ii** read for **h** ("tiie" for "the") and **li** read for **h**
("liis" for "his"). This file records what is damaged. **The repository is not
corrected.** Leaving the damage visible is deliberate: a silent repair across
primary texts is a correct-and-quote edit, and this project does not do those.
Sessions and entry writers should read around it and never quote a damaged token
as though it were the printed word.

**Totals.** 852 distinct damaged forms, 8,827 occurrences, across a
repository of 11,444,216 words — about 0.077%.

**How this list was derived.** A form is listed only if it is not a Roman
numeral, and if the repaired form appears at least 50 times in this repository
and at least 20 times more often than the damaged form. That is corpus evidence,
not judgement: "tiie" is listed because "the" occurs 768,985 times.
Forms failing that test are excluded even where a human would read them easily.
