# Quoting modern sources in Patristica entries

For entry writers. This is about what to do when the best witness to something is
a book still in copyright.

## The rule

**Quote briefly, name the edition, and only where the entry is discussing the
passage.** A sentence or two inside commentary that is doing real work on it is
ordinary criticism. It is how a reference guide is supposed to treat scholarship
it disagrees with, relies on, or wants the reader to weigh.

**Do not build files of extracts.** This repository hosts files that anyone can
fetch from a public URL. A quotation inside an entry is commentary; a file of
quotations on GitHub is redistribution with extra steps, and volume is exactly
what turns the first into the second. Nothing in copyright gets its own file
here, no matter how short the excerpts are individually.

This is the same reasoning that keeps Luther's *On the Jews and Their Lies* out
of the repository while the Luther entry still quotes it. See
`reformation/NOTE-on-the-jews-and-their-lies.md`.

## Where a modern source is genuinely irreplaceable

Some things have no public-domain witness and never will, because the text was
recovered or the argument was made too recently:

- **Melito, *On Pascha*** — recovered in the twentieth century, so every English
  translation is modern. Stewart-Sykes (St Vladimir's, Popular Patristics 20).
- **Luther, *On the Jews and Their Lies*** — Bertram's translation in *Luther's
  Works*, American Edition vol. 47 (Fortress, 1971).
- **Dating the Crosby-Schøyen Codex** — Lundhaug, *BASP* 57 (2020).

In these cases quote a short passage, cite the edition by translator, publisher
and year, and let the entry carry the argument. The reader should be able to see
that the entry knows what the source says.

## Where a modern source is not needed at all

Most of the time the copyrighted book has a free equivalent that can be quoted at
any length. Reach for these first:

- **English Bible** — the King James Version and the American Standard Version
  (1901) are both in `scripture/`. The Revised Version (1885), the 1917 JPS
  Tanakh and the World English Bible are equally free. The ESV is not, and buys
  nothing these do not.
- **Greek New Testament** — Tischendorf's 8th edition is in `scripture/`.
  Westcott-Hort, Tregelles and the Textus Receptus are free, and the SBL Greek
  New Testament is openly licensed. Nestle-Aland and the UBS text are the
  editors' work and are not free.
- **Septuagint** — Brenton (1851).
- **Hebrew** — the Westminster Leningrad Codex, not Biblia Hebraica
  Stuttgartensia.
- **Study notes and commentary** — write them. That is what this app is.

## Two things that are never acceptable

**Machine translation.** A file whose provenance is an AI translation is rejected
regardless of how well it reads and regardless of the original's copyright
status. It has no translator, no edition, and nobody who checked it. See
SOURCING.md.

**Pirated copies.** Several files supplied to this project carry the filename
markers of known pirate sites. Quoting from one does not change the copyright
analysis much, but for a paid product it is not a defensible place to be
standing. Quote from a copy you can name and account for.

## If in doubt

Most publishers grant permission for modest quotation free on request, and
several — Crossway and the Deutsche Bibelgesellschaft among them — publish
standing quota policies. Asking costs an email. For a firm threshold on a
commercial product, that is a question for a lawyer rather than for a session.
